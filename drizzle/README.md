## `0000_uuid_v7.sql` is hand-written

drizzle-kit generates table DDL from the schema files. It does not generate the
`gen_random_uuid_v7()` function that `common/db/columns.ts` `id()` defaults to,
and every table needs it before it can be created.

The function is native in **Postgres 18**; the docker-compose image is PostGIS
on **Postgres 16**, so this is a plpgsql shim with interchangeable output.
When the image moves to 18, delete the file and drop the journal entry.

Verified against the running database: version nibble `7`, RFC 4122 variant,
and ordered across milliseconds. **Not** monotonic *within* a millisecond —
v7 does not promise that without a counter, and it does not need to: the point
is that inserts cluster at the right edge of the index rather than scattering
like v4.
